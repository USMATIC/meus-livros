Confirmação automática do PIX — V9: o Worker V9 já está preparado para integração opcional com Mercado Pago Checkout Transparente (Orders API + Webhook). Com o Worker V9 e o Mercado Pago configurados, cada pedido recebe um PIX dinâmico exclusivo. O Webhook consulta a Order no Mercado Pago e somente quando o status for processed / accredited e o valor coincidir com o total do pedido o Sistema registra PIX CONFIRMADO, data/hora e baixa o estoque. Em modo teste, o Worker usa o fluxo oficial de teste do Mercado Pago; em produção, usa os dados reais do comprador. Sem credenciais, permanece disponível o modo manual de contingência.
